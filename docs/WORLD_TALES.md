# 万物奇想记：角色的好奇心如何长成一个世界

2026-10-23 · 第三章 · 本文描述已经接入本地游戏的内容。

## 研究带来的设计方向

POP MART 的官方介绍把 LABUBU 放在一个有族群、伙伴关系和稳定性格的森林世界里；不同外观依然能指向同一个人物。MOLLY 的官方介绍强调绘画、想象力和探索欲，主题系列因此可以理解为她对不同生活的尝试。[LABUBU 官方介绍](https://www.popmart.com/cz/ip/labubu/7549cf2c-6db2-4e02-ab69-026be178d334) · [MOLLY 官方介绍](https://www.popmart.com/us/collection/molly)

这里提取的是叙事方法。下面的居民、地点、道具、故事和三维造型均围绕浮屿工坊自身的世界规则创作。

1. **辨识点不变，生活不断变化。** 啵啵始终保留折纸耳朵与送信的心愿；试飞员和面团鸟，是它尝试送达问候的两种方式。
2. **兴趣需要一个可以走进去的地方。** 米糯的茶壶不只挂在身上，它对应一场由玩家参与的倒雨茶会。
3. **角色关系推动事件。** 澄澄带来回声，咔哒带来节拍；两个兴趣相遇，才长出水母剧院。
4. **系列之间留下生活痕迹。** 新地点有固定主形、相伴的小生命和互动结尾；重访时，已完成的地点保留亮起的装饰。
5. **收藏来自经历。** 玩家完成故事后收下一张明信片，日光、月色、天候各有一个版本。所有故事都可主动体验，没有抽取或付费机制。

## 世界的新一层规则

奇想群岛里，认真对待的小心愿会凝成地方和生命。居民还有一种能力：把好奇心借给别的生命一天。米糯可以体验萤火虫如何照路，巴斯可以背上蜗牛壳理解“慢一点”。身体的轮廓和在意的事情没有消失，体验会变成新衣服、新朋友和新的共同生活。

各地出现了“奇想剧场”：它们不是有舞台边界的演出场，而是居民把一件小事做得太认真之后长出的场所。邮局开始烤面包，绿洲开始散步，图书馆把没写完的地方留给后来的人。邀请朋友参与，奇妙才会发生。

现有九区、十八段冒险和生活角继续存在；剧场分布在聚落旁与旅行途中的空地，可步行、驾驶到达，也可从手册或地图的 ✧ 直达。靠近剧场会遇见主办居民与一位来做客的朋友；其原来位置的模型暂时隐藏，离开后恢复。客串关系由地点固定配置，不是模拟完整居民日程。

每处有独立三维地标、四只当地小生命、三处实体交互点、主办者与来客对话。回应完成后，小生命会升起或开始巡游，场景灯饰亮起，并显示一段专属结尾。

目前三个互动类型分别为时机、音序、空间寻找。不同地点使用各自的道具、配方和故事；这些是轻量互动，不是九套大型小游戏。音序的提示始终可读，按错可重来；时机没有失败惩罚；寻找类必须走到实体标记旁。

## 日光、月色与天气

每个地点三张故事卡，共 27 张，全部在手册中可以看到收集条件。

- **日光篇：**晴朗或多云，游戏时间 06:00–18:00。
- **月色篇：**晴朗或多云，游戏时间 18:00–次日 06:00。
- **天候篇：**细雨、落雪或星辉，不限时间。三种天气共用该地点的一张天候卡。

开始互动时确定本次版本，途中调整天气不会改变已经开始的故事。环境本身仍按当前天气和时间渲染。每张新卡赠一粒花种，重玩不重复发放。完成过的地点留下装饰灯；九处都完成后，故事集显示“万物来信节”结语。目前这一结语是收集里程碑，并没有另做大型全岛节庆演出。

例如借月灯塔，白天是月亮晒被子，夜晚是给晚归人照路，雨雪里则是灯蛾把微光传往下一站。同一个地方的玩法一致，但事件意义、结尾文本和环境氛围改变。

## 操作与保存

左上角“奇想剧场”打开故事集，点击“去赴这场约”。地图上九枚 ✧ 也可直达。H 开始或参与，E 与剧场两侧的居民交谈；音序玩法另有可点按的名字按钮，触屏用户可用底部按钮操作。原有 Q 区域奇遇、T 冒险、M 地图仍可使用。

JSON 升级到 v6，新增 `tales.cards` 和 `tales.visited`，记录明信片和到访地点。v2–v5 存档继续读取，缺失故事字段时从空白故事集开始。新增造型选择沿用每位角色独立存储的 `looks`。

剧场互动进行到一半的音序、时机和寻找过程不存档，离开剧场或读档后重来；完成的明信片和奖励会随手动存档保存。打开手册会暂停时机游戏的进度。重新生成世界会清空当前剧场进度，但不会覆盖上一次手动存档。

## 实现入口与边界

验证：新剧场专项 47 项、衣橱与存档回归 131 项、实际部署检查 12 项已通过。专项测试实际推进了九处地点各三种版本的交互，另检查实体站点碰撞、重复奖励、v5 迁移、v6 保存恢复、错误输入、移动布局和浏览器错误；并查看了故事集、茶会、月塔、空港、书屋与手机界面的实机截图。测试报告位于 `.local/`。这些检查不能代替长期游玩和更多真实设备的性能测试。

- `world-tales.js`：地点、两个造型系列、三种互动、居民客串、明信片、场景模型与动画。
- `world-tales.css`：故事集、地图入口、互动面板与手机布局。
- `index.html`：模型造型扩展、模块接入、地图／手册入口、v6 存档、输入与主循环。
- `scripts/verify-tales.cjs`：九处三版本玩法、重复奖励、旧档迁移、输入清洗、实体点可达性和界面检查。

内容是本地编写的确定性故事，没有在线生成剧情。居民没有自主作息、关系数值或长期成长。音乐类事件目前通过光与动作表达，游戏仍没有音频。进一步扩展可以从角色关系与多步跨区故事入手；新增地点应当带来新的生活动机或空间行为，避免仅增加收集数量。
